# شطرنج آنلاین

بازی شطرنج تحت وب (یک فایل `index.html`) با حالت بازی با کامپیوتر و دو نفره، سه سطح هوش مصنوعی و حالت‌های:
استاندارد، پیاده‌های کناررو، هر چیزی را بزن، شاه تپه، ۳ کیش، اژدر، چشم‌بسته و بدون قلعه.

اجرا: صفحه را از طریق GitHub Pages باز کن یا مستقیماً `index.html` را در مرورگر اجرا کن.
